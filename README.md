## 🚀 Main Project

### ⚾ Dugout — AWS 기반 KBO End-to-End 데이터 플랫폼 `2026.01 ~`

[![Repo](https://img.shields.io/badge/GitHub-Dugout--Data--Platform-181717?style=flat&logo=github)](https://github.com/SungChul23/Dugout-Data-Platform)
[![Service](https://img.shields.io/badge/Service-dugout.cloud-8b5cf6?style=flat)](https://dugout.cloud/)

> KBO 데이터를 매일 자동 수집하고,  
> 저장·분석·ML·GenAI·서비스까지 연결한 End-to-End 데이터 플랫폼입니다.

#### Data Pipeline
- EventBridge → Step Functions → **5개 Lambda 병렬 수집**
- 일일 약 **690건**의 KBO 데이터 자동 수집 및 처리
- S3 Bronze → Transform → S3 Silver 구조로 데이터 레이크 구성
- Lambda가 DB에 직접 적재하지 않고 Spring REST API를 경유하도록 적재 경로 통일

#### Data Lake & Analytics
- S3 + Glue Catalog + Athena 기반 분석 환경 구축
- CSV → Parquet 전환으로 Athena 스캔량 **43.4% 감소**
- `year` Partition 기반 Partition Pruning으로 스캔량 **64.6% 감소**
- 조회 패턴에 맞춰 월/일이 아닌 연도 기준 파티션 설계

#### Pipeline Optimization
- Selenium + Chromium 기반 수집 구조를 `requests + BeautifulSoup`으로 재설계
- 실행 시간 **98.56s → 23.85s**
- Lambda 최대 메모리 사용량 **960MB → 233MB**
- 미등록 신규 선수 유입 시 `missing-player-scraper`를 동적 호출해 FK 정합성 자동 복구

#### ML / GenAI Pipeline
- SageMaker 기반 XGBoost 학습 및 배치 추론
- SHAP 기반 예측 기여도 산출
- `gg-explainer` Lambda에서 Amazon Bedrock을 호출해 AI 리포트 생성
- Golden Glove 예측 **Top-1 Accuracy 76.9%**
- 예측 결과, SHAP, AI 리포트를 S3 Gold에 보존하고 Service DB를 통해 서비스 제공

#### Text-to-SQL
- 자연어 질의 → Bedrock SQL 생성 → SQL Validator → Service DB 조회
- SELECT만 허용하고 DDL/DML 차단
- `EXPLAIN ANALYZE` 기반 병목 분석 후 인덱스 적용
- 약 **4.1만 행 Full Scan 제거**, `18.5ms → 0.64ms`

#### Team Recommendation
- 사용자 입력 조건을 기반으로 Athena에서 팀 추천 분석 수행
- Spring Boot가 Athena 조회 결과를 Bedrock에 전달해 자연어 추천 리포트 생성

`Python` `SQL` `AWS Lambda` `Step Functions` `EventBridge` `S3` `Glue` `Athena` `SageMaker` `Bedrock` `Spring Boot`
